Layout Rules

First viewport

The core object or offer must be obvious before scrolling.

Spacing

Use generous section padding, but keep cards and tools dense enough to scan.

Mobile

Complex grids collapse into a deliberate order, not a random stack.

Reuse

Each recipe should work with different text and imagery without breaking.
