How this repo should grow

Study a design, extract the pattern, rebuild it as a reusable part.

  1. CaptureSave the reference URL, screenshot notes, and section type.
  2. AbstractName the layout behavior, content slots, tokens, and responsive rules.
  3. RebuildCreate original HTML/CSS that carries the same design idea.
  4. CatalogAdd it to the preview site with metadata and copy instructions.
