# Metro Grid

Use this layout for feature overviews, service menus, portfolio hubs, and category pages.

## Structure

- One wide tile for the primary message
- One tall tile for a premium or highlighted idea
- Two to four supporting tiles
- Mobile order should keep the primary tile first and the highlighted tile second

## Best For

- Agency service sections
- SaaS feature blocks
- Portfolio category grids
- Homepage section menus
